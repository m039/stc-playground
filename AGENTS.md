### 1. Работать только в ветке `develop`
* Основная рабочая ветка для всей разработки — **`develop`**.
* Прямой пуш и прямые коммиты в ветку `main` **СТРОГО ЗАПРЕЩЕНЫ** (`main` — стабильная ветка).
* Все новые фичи, исправления и задачи начинаются от ветки `develop` (например, `feature/...`, `fix/...`, `docs/...`) либо коммитятся в рамках рабочего потока `develop`.

### 2. При каждом выполнении задач ОБЯЗАТЕЛЬНО делать Pull Request
* По завершении ЛЮБОЙ задачи, этапа разработки или фичи разработчик / AI обязан:
  1. Зафиксировать изменения в отдельной ветке задачи (ответвлённой от `develop`).
  2. Создать **Pull Request (PR)** с базовой веткой **`develop`** (`base: develop <- head: <branch>`).
  3. В описании PR чётко указать:
     - Список выполненных задач и изменений;
     - Затронутые примеры / модули (`Code/<пример>`, `PCB/`, модули FwLib_STC8, `Docs/`);
     - Результат сборки (успешная сборка через PlatformIO / SDCC) и использование памяти (Flash/Code и RAM в байтах / %).
* Никаких задач без оформленного Pull Request.

## 🛠 АРХИТЕКТУРА И СТРУКТУРА ПРОЕКТА `stc-playground`

Проект представляет собой коллекцию примеров прошивок (firmware) для микроконтроллеров **STC8G / STC8H** (8-битное ядро, совместимость с 8051), собирается на PlatformIO (platform `intel_mcs51`, компилятор SDCC) с HAL-библиотекой [FwLib_STC8](https://github.com/IOsetting/FwLib_STC8):

| Директория | Описание |
| :--- | :--- |
| `Code/blink/` | Базовый пример мигания светодиода на **P5.5** (проект PlatformIO, MCU **STC8G1K17A**, IRC 11.0592 MHz). Пользовательский код — `src/main.c`, определение платы — `boards/STC8G1K17AX.json` |
| `Code/blink/lib/FwLib_STC8/` | HAL-библиотека FwLib_STC8: заголовки `include/fw_*.h`, исходники `src/fw_*.c` и эталонные примеры по модулям (`demo/`: adc, clock, gpio, i2c, iap, mem, pca, pwm, rtc, spi, tim, uart, usb, wdt) — источник для новых задач |
| `Code/button/` | Кнопка на P3.2 через внешнее прерывание INT0: реакция сразу в ISR, быстрое мигание при удержании / медленное при отпускании (проект PlatformIO) |
| `Code/button-pwm/` | ШИМ-«дыхание» PCA2 на P5.5 (8-bit, ~43 кГц), кнопка P3.2 переключает скорость цикла (проект PlatformIO) |
| `PCB/` | Печатная плата STC8G1K017A_Devboard: проект EasyEDA Pro (`.eprj2`), превью платы и схемы (`img/`), README |
| `Docs/` | Вендорская документация: «STC8G-8H 库函数使用说明» (PDF), даташит STC8G (EN), архив демо-кода от вендора |

**Конвенция**: каждый пример — автономный проект PlatformIO в отдельной папке под `Code/` (`platformio.ini`, `src/main.c`, локальная копия FwLib_STC8 в `lib/FwLib_STC8`). Новые примеры создаются по образцу существующих, стартовый код берётся из демо `FwLib_STC8/demo/`.

**Приписка к README (обязательна)**: каждый README проекта (корневой `README.md`, `Code/<пример>/README.md`, `PCB/README.md`) обязан заканчиваться припиской — после разделителя `---`, на отдельной строке, курсивом, дословно:

> *Комментарии к коду и этот README составлены Qwen 3.8.*

## 🎯 СПЕЦИФИКА ОГРАНИЧЕНИЙ STC8G / STC8H

* **Ядро**: 8-бит (совместимость с 8051), одноцикловые инструкции, тактовая частота до 48 MHz (STC8G) / 96 MHz (STC8H).
* **Ресурсы рабочей платы STC8G1K17A**: Flash ~**17 KB** (code-пространство 17408 байт), RAM — IRAM **256 B** + XRAM **1 KB** (heap 128 B). Лимит очень жесткий.
* **Стек**: растёт в IRAM — избегать глубоких цепочек вызовов и рекурсии: они съедают память данных вместе с локальными переменными.
* **Тактирование**: `__CONF_FOSC` в `platformio.ini` обязан точно соответствовать реальному такту MCU (кварц/IRC), иначе все тайминги, задержки и UART будут неверны.
* **Модель MCU**: `__CONF_MCU_MODEL=MCU_MODEL_STC8G1K...` выбирает карту регистров FwLib_STC8; несовпадение модели = «магическое» поведение без ошибок компилятора.
* **Оптимизация** (аналогично PDK): использовать макросы вместо мелких статических функций (SDCC не инлайнит), минимизировать 16-битные вычисления и дублирование циклов; Code/RAM держать в пределах лимитов платы из `boards/*.json`.
* **Прошивка**: протокол `stcgal` — STC-ISP / STC-GAL (UART, без reset), либо PlatformIO: `pio run -t upload`.
