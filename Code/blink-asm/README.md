# blink-asm

STC8G1K17A (IRC 11.0592 MHz) — мигание того же светодиода, но чистым SDCC-ассемблером (`sdas8051`), без C и FwLib_STC8: аналог [`blink`](../blink).

## Что делает программа
Светодиод на **P5.5** мигает с симметричным циклом: горит 1 с → гаснет 1 с. Всё в главном цикле `src/main.s`: без прерываний, без стека (функций нет). Режим GPIO выставляется напрямую через SFR-регистры (`P5M0`/`P5M1`), задержка расписана под IRC: `175 × 250 × 250 ≈ 11,03M циклов ≈ 1 с`.

## Пины
| Pin | Назначение | Режим |
| :-- | :--------- | :---- |
| P5.5 | Выход на светодиод: активный уровень высокий (`SET` → горит) | Output, push-pull |

## Сборка / загрузка
`pio run -t upload`.
