# blink

STC8G1K17A (IRC 11.0592 MHz, HAL FwLib_STC8) — базовый пример мигания светодиода.

## Что делает программа
Светодиод на **P5.5** мигает с асимметричным циклом: гаснет 100 мс → горит 1 с, так далее. Без входов и прерываний — всё в главном цикле `src/main.c`.

## Пины
| Pin | Назначение | Режим |
| :-- | :--------- | :---- |
| P5.5 | Выход на светодиод: активный уровень высокий (`P55 = SET` → горит) | Output, push-pull |

Сборка/загрузка: `pio run -t upload`.
