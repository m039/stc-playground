# button-pwm

STC8G1K17A (IRC 11.0592 MHz, HAL FwLib_STC8) — переписанный пример `button`: вместо моргания светодиод на P5.5 **плавно вспыхивает и плавно гаснет** («дыхание») за счёт аппаратной ШИМ (модуль PCA), а при нажатой кнопке весь цикл идёт быстро.

## Что делает программа
Светодиод на **P5.5** управляется каналом 2 модуля PCA (`CCP2 → P5.5`, опция портов `PCA_AlterPort_G1K08A_P31_P32_P33_P55`) с 8-битной скважностью (`CCAP2H = 0..255`). Источник тактирования ШИМ — SYSCLK (один шаг CCAP = один системный цикл ≈90 нс, частота ШИМ ≈43 кГц), поэтому глаз усредняет скважность без мерцания.

Главный цикл с периодом **20 мс** читает кнопку на P3.2 и каждый тик меняет яркость светодиода на один шаг — по треугольному циклу «вспыхивание → гашение»:
- кнопка отпущена — шаг `STEP_SLOW` = 2 (одна фаза ~2,6 с, полный цикл ~5 с);
- кнопка нажата — шаг `STEP_FAST` = 16 (одна фаза ~0,3 с, полный цикл ~0,6 с).

В точке полной яркости и в точке полного гашения направление меняется автоматически — переходы плавные, без резких вспышек. Режим затухания меняется в течение одного тика (≤20 мс), поэтому достаточно опроса P3.2: внешнее прерывание INT0 не используется, что экономит флеш и RAM по сравнению с `button`. Каналы PCA 0/1 выключены (`PCA_WorkMode_None`), поэтому P3.2 остаётся обычным GPIO-входом.

> **Важно (измерено на плате)**: выход CCP2 на P5.5 у STC8G1K08A инверсный относительно CCAP2H — эффективная скважность = 1 − CCAP2H/256, т.е. `CCAP2H=FF` ≈ выключен и `CCAP2H=0` → полная яркость (вендорские демо этого не документируют). Поэтому интуитивная переменная `brightness [0..255]` (0 = выключен) конвертируется в значение сравнения макросом `CCP_VALUE()` в единственной точке записи.

## Пины
| Pin | Назначение | Режим |
| :-- | :--------- | :---- |
| P3.2 | Вход кнопки; внутренний pull-up включён; низкий уровень = нажата (опрос в цикле) | Input, high-impedance |
| P5.5 | Выход на светодиод: ШИМ PCA канал 2 (CCP2); вывод инверсный относительно CCAP2H (измерено): CCAP2H=0 → полная яркость, CCAP2H=FF ≈ выключен; яркость [0..255] конвертируется макросом `CCP_VALUE()` | Output, push-pull |

Сборка/загрузка: `pio run -t upload`.
