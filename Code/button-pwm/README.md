# button-pwm

STC8G1K17A (IRC 11.0592 MHz, HAL FwLib_STC8) — переписанный пример `button`: вместо моргания светодиод на P5.5 плавно **затухает** за счёт аппаратной ШИМ (модуль PCA), а при нажатой кнопке затухание идёт быстро.

## Что делает программа
Светодиод на **P5.5** управляется каналом 2 модуля PCA (`CCP2 → P5.5`, опция портов `PCA_AlterPort_G1K08A_P31_P32_P33_P55`) с 8-битной скважностью (`CCAP2H = 0..255`). Источник тактирования ШИМ — SYSCLK (один шаг CCAP = один системный цикл ≈90 нс, частота ШИМ ≈43 кГц), поэтому глаз усредняет скважность без мерцания.

Главный цикл с периодом **20 мс** читает кнопку на P3.2 и уменьшает яркость светодиода на один шаг:
- кнопка отпущена — шаг `STEP_SLOW` = 2 (полное затухание ~2,6 с);
- кнопка нажата — шаг `STEP_FAST` = 16 (полное затухание ~0,3 с).

При отрицательном переполнении (недоходе) счётчик яркости 8 бит автоматически «заворачивается» к полной яркости, и цикл начинается заново — плавный аналог периода из `blink`/`button`. Режим затухания меняется в течение одного тика (≤20 мс), поэтому достаточно опроса P3.2: внешнее прерывание INT0 не используется, что экономит флеш и RAM по сравнению с `button`. Каналы PCA 0/1 выключены (`PCA_WorkMode_None`), поэтому P3.2 остаётся обычным GPIO-входом.

## Пины
| Pin | Назначение | Режим |
| :-- | :--------- | :---- |
| P3.2 | Вход кнопки; внутренний pull-up включён; низкий уровень = нажата (опрос в цикле) | Input, high-impedance |
| P5.5 | Выход на светодиод: ШИМ PCA канал 2 (CCP2), активная скважность высокая (`CCAP2H=FF` → горит на полную) | Output, push-pull |

Сборка/загрузка: `pio run -t upload`.
