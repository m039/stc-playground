# button-pwm

STC8G1K17A (IRC 11.0592 MHz, HAL FwLib_STC8) — плавное свечение яркости светодиода на P5.5 за счёт аппаратной ШИМ PCA вместо мигания.

## Что делает программа
**Свечение** — плавная модуляция яркости: светодиод плавно разгорается до максимальной яркости и затем плавно гаснет; цикл повторяется без резкого включения/выключения.

Светодиод на **P5.5** управляется каналом 2 модуля PCA с 8-битной скважностью (ШИМ ~43 кГц). Главный цикл (период **20 мс**) каждый тик меняет яркость на один шаг по треугольному циклу «вспыхивание → гашение»:
- кнопка отпущена — шаг `STEP_SLOW` = 2 (полный цикл ~5 с);
- кнопка нажата — шаг `STEP_FAST` = 16 (полный цикл ~0,6 с).

Кнопка **P3.2** опрашивается в цикле (внешнее прерывание INT0 не используется).

## Пины
| Pin | Назначение | Режим |
| :-- | :--------- | :---- |
| P3.2 | Вход кнопки; внутренний pull-up включён; низкий уровень = нажата (опрос в цикле) | Input, high-impedance |
| P5.5 | Выход на светодиод: ШИМ PCA канал 2 (`CCP2`) | Output, push-pull |

## Сборка / загрузка
`pio run -t upload`.
