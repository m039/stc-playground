# button

STC8G1K17A (IRC 11.0592 MHz, HAL FwLib_STC8) — пример реакции на кнопку через внешнее прерывание INT0 без опроса.

## Что делает программа
Кнопка подключена к линии **P3.2**, которая у семейства STC8G/STC8H закреплена за внешним прерыванием **INT0**. ISR `Button_Routine` (запуск по обоим фронтам) мгновенно, прямо в прерывании, меняет состояние светодиода на P5.5 и ставит флаг `pressed`. Главный цикл мигает светодиод по флагу:
- кнопка зажата — быстрое мигание (100/100 мс);
- отпущена — медленное мигание (1 с / 1 с).

Замена блокирующего `SYS_Delay` на разбивку по 5-мс слайсам (`Delay_Interruptible`) позволяет сменить режим в течение ≤5 мс после нажатия/отпускания.

## Пины
| Pin | Назначение | Режим |
| :-- | :--------- | :---- |
| P3.2 | Вход кнопки, линия INT0; внутренний pull-up включён; низкий уровень = нажата (падение запускает ISR) | Input, high-impedance |
| P5.5 | Выход на светодиод: активный уровень низкий (`P55 = RESET` → горит) | Output, push-pull |

Сборка/загрузка: `pio run -t upload`.
